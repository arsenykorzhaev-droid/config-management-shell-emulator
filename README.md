# VFS Emulator — Этап 2

Эмулятор командной оболочки UNIX-подобной ОС с виртуальной файловой системой.

**Вариант:** №12 (ИКБО-63-25)
**Этап:** 2 — Конфигурация
**Язык реализации:** Python 3.10+

---

## Общее описание

Приложение реализует интерактивный REPL-интерфейс (Read-Eval-Print Loop) с графическим интерфейсом (GUI) на базе библиотеки Tkinter. Эмулятор имитирует работу в командной строке UNIX-подобной ОС.

На Этапе 2 добавлена возможность настройки эмулятора через параметры командной строки и стартовый скрипт, который автоматически выполняет команды при запуске.

---

## Функции

### Реализованные команды

| Команда | Описание |
|---------|----------|
| `ls [args]` | Вывести содержимое директории (заглушка). |
| `cd [path]` | Сменить текущую директорию (заглушка). |
| `help` | Показать список доступных команд. |
| `exit` | Завершить работу эмулятора. |

### Дополнительные возможности

- Раскрытие переменных окружения — поддержка синтаксиса `$VAR` и `${VAR}`.
- Обработка кавычек — парсер корректно обрабатывает аргументы в кавычках.
- Обработка ошибок — при вводе неизвестной команды или неверных аргументов выводится сообщение об ошибке.
- Заголовок окна — содержит имя VFS.
- Отладочный вывод параметров — при запуске отображаются переданные параметры (`vfs_path`, `script_path`).
- Стартовый скрипт — автоматически выполняет команды из файла, поддерживает комментарии (`#`), отображает как ввод, так и вывод.

---

## Настройки

На Этапе 2 настройки задаются через аргументы командной строки:

- `--vfs-path` — путь к физическому расположению VFS.
- `--script` — путь к стартовому скрипту.
