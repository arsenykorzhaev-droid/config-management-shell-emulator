# VFS Emulator

Эмулятор командной оболочки UNIX-подобной ОС с виртуальной файловой системой.

**Вариант:** №12 (ИКБО-63-25)
**Этап:** 1 — REPL (минимальный прототип)
**Язык реализации:** Python 3.10+

---

## Общее описание

Приложение реализует интерактивный REPL-интерфейс (Read-Eval-Print Loop) с **графическим интерфейсом (GUI)** на базе библиотеки Tkinter. Эмулятор имитирует работу в командной строке UNIX-подобной ОС.

На текущем этапе реализован минимальный прототип: большинство команд представляют собой заглушки, но диалог с пользователем уже поддерживается. Ввод и вывод происходят в окне: сверху — область вывода, снизу — поле ввода с приглашением `> `.

---

## Функции

### Реализованные команды

| Команда | Описание |
|---------|----------|
| `ls [args]` | Вывести содержимое директории (заглушка). |
| `cd [path]` | Сменить текущую директорию (заглушка). |
| `help` | Показать список доступных команд. |
| `exit` | Завершить работу эмулятора. |

### Дополнительные возможности

- **Раскрытие переменных окружения** — поддержка синтаксиса `$VAR` и `${VAR}`. Например, ввод `cd $HOME` автоматически подставит значение переменной окружения `HOME`.
- **Обработка кавычек** — парсер корректно обрабатывает аргументы в кавычках. Например, `ls "моя папка"` воспринимается как один аргумент.
- **Обработка ошибок** — при вводе неизвестной команды или неверных аргументов выводится сообщение об ошибке, работа REPL не прерывается.
- **Заголовок окна** — содержит имя VFS (например, `Эмулятор оболочки - MyVFS`).

---

## Настройки

На текущем этапе настройки задаются константами в коде:

- `vfs_name` — имя VFS, отображаемое в заголовке окна и приветствии (по умолчанию: `MyVFS`).
- `PROMPT` — приглашение к вводу (по умолчанию: `> `).

В следующих этапах настройки будут вынесены в аргументы командной строки и конфигурационные файлы.
