## 1. Общее описание
Минимальный прототип CLI-приложения для визуализации графа зависимостей менеджера пакетов .NET (NuGet). На данном этапе приложение считывает настройки из конфигурационного файла формата JSON, проверяет их и выводит в консоль в формате ключ-значение.

## 2. Описание функций и настроек
**Параметры командной строки:**
- `--config` — путь к JSON-файлу конфигурации (обязательный параметр).

**Настраиваемые параметры в JSON:**
- `package_name` — имя анализируемого пакета.
- `repo_url` — URL-адрес репозитория.
- `test_mode` — режим работы с тестовым репозиторием (true/false).
- `output_file` — имя сгенерированного файла с изображением графа.
- `ascii_tree` — режим вывода в формате ASCII-дерева (true/false).
- `filter_substring` — подстрока для фильтрации пакетов.

**Обработка ошибок:**
- Проверка наличия файла конфигурации.
- Проверка корректности синтаксиса JSON.
- Проверка наличия всех обязательных ключей в конфигурации.

## 3. Запуск
```bash
python src/main.py --config src/config.json
