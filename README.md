## 1. Общее описание
На втором этапе в CLI-приложение добавлена основная логика получения данных о зависимостях. Программа извлекает информацию о прямых зависимостях заданного пользователем пакета из формата .NET (NuGet), не используя сторонние библиотеки менеджеров пакетов.

## 2. Описание функций и настроек
**Параметры командной строки:**
- `--config` — путь к JSON-файлу конфигурации.

**Основные функции:**
- Чтение JSON-конфигурации.
- Обращение к официальному API NuGet (v3-flatcontainer) для получения списка версий пакета.
- Скачивание файла описания пакета `.nuspec`.
- Парсинг XML-файла (с помощью регулярных выражений) для извлечения прямых зависимостей.
- Вывод списка прямых зависимостей в консоль.

**Режим тестирования:**
Если в конфигурации включен `test_mode: true`, приложение не делает сетевых запросов, а использует захардкоженный список зависимостей для демонстрации работы.

## 3. Запуск
```bash
python src/main.py --config src/config.json
