## Общее описание

Репозиторий содержит практические работы по дисциплине «Конфигурационное управление». Реализован эмулятор командной оболочки UNIX-подобной ОС с графическим интерфейсом (GUI) на базе библиотеки Tkinter.

Разработка велась поэтапно, каждый этап — в отдельной ветке:

| Ветка | Этап | Что реализовано |
|-------|------|-----------------|
| `stage-1` | REPL | Минимальный прототип: GUI, парсер, заглушки `ls`, `cd`, `help`, `exit` |
| `stage-2` | Конфигурация | Параметры командной строки (`--vfs-path`, `--script`), стартовый скрипт |
| `stage-3` | VFS | Загрузка виртуальной файловой системы из XML, команды `ls`, `cd`, `pwd`, `cat` |
| `stage-4` | Основные команды | Команды `rev`, `history`, `find` |
| `stage-5` | Дополнительные команды | Команды `rm`, изменение состояния VFS |

Текущая ветка `main` — содержит только базовую структуру репозитория (README, .gitignore, пустые папки).

## Возможности эмулятора

### Реализованные команды

| Команда | Описание |
|---------|----------|
| `ls [path]` | Вывести содержимое директории. |
| `cd [path]` | Сменить текущую директорию. |
| `pwd` | Показать текущую директорию. |
| `cat <file>` | Показать содержимое файла. |
| `rev <file>` | Вывести содержимое файла в обратном порядке. |
| `history` | Показать историю введённых команд. |
| `find <name>` | Найти файл или папку по имени. |
| `rm <path>` | Удалить файл или папку (в памяти). |
| `help` | Показать список команд. |
| `exit` | Завершить работу эмулятора. |

### Дополнительные возможности

- Раскрытие переменных окружения — поддержка `$VAR` и `${VAR}`.
- Обработка кавычек — парсер корректно разбирает аргументы в кавычках (`shlex`).
- Обработка ошибок — при неизвестной команде или неверных аргументах выводится сообщение, REPL не прерывается.
- Заголовок окна — содержит имя VFS.
- Отладочный вывод параметров — при запуске отображаются `vfs_path` и `script_path`.
- Стартовый скрипт — поддерживает комментарии (`#`), выводит и ввод, и результат.
- VFS в памяти — все операции производятся в памяти, исходный XML не изменяется.

## Запуск

### Без параметров

```bash
./run.sh
```

или

```bash
python src/main.py
```

или через Makefile:

```bash
make run
```

С параметрами

```bash
./run.sh --vfs-path vfs_data/default.xml --script scripts/test.txt
```

или

```bash
python src/main.py --vfs-path vfs_data/default.xml --script scripts/test.txt
```

Справка

```bash
python src/main.py --help
```

Аргументы командной строки

Аргумент Обязательный Описание
--vfs-path Нет Путь к XML-файлу VFS.
--script Нет Путь к стартовому скрипту.

---

Формат VFS (XML)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<vfs name="MyVFS">
    <dir name="home">
        <dir name="user">
            <file name="readme.txt">Содержимое файла.</file>
        </dir>
    </dir>
    <file name="motd.txt">Привет!</file>
</vfs>
```

Пример использования

После запуска откроется окно. Введите команду в поле ввода и нажмите Enter:

Ввод Результат
pwd /
ls etc/, home/, motd.txt
cd /home/user (переход в директорию)
pwd /home/user
ls notes.txt, readme.txt
cat readme.txt Это тестовый файл в VFS.
rev readme.txt ВFS в йалф йовотэт этО
history Список введённых команд
find readme.txt Путь к найденному файлу
rm /home/user/notes.txt Файл удалён (в памяти)
help Список команд
exit Закрытие окна
