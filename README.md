# VFS Emulator — Этап 3

Эмулятор командной оболочки UNIX-подобной ОС с виртуальной файловой системой.

**Вариант:** №12 (ИКБО-63-25)
**Этап:** 3 — VFS
**Язык реализации:** Python 3.10+

---

## Общее описание

Приложение реализует REPL-интерфейс с GUI на базе Tkinter.

На Этапе 3 добавлена **виртуальная файловая система (VFS)**, загружаемая из **XML-файла**. Все операции производятся **в памяти** — исходный XML не модифицируется.

---

## Функции

### Реализованные команды

| Команда | Описание |
|---------|----------|
| `ls [path]` | Вывести содержимое директории. |
| `cd [path]` | Сменить текущую директорию. |
| `pwd` | Показать текущую директорию. |
| `cat <file>` | Показать содержимое файла. |
| `help` | Список команд. |
| `exit` | Выход. |

### Дополнительные возможности

- Загрузка VFS из XML-файла.
- Обработка ошибок загрузки: файл не найден, неверный формат.
- Раскрытие переменных окружения (`$VAR`).
- Обработка кавычек (`shlex`).
- Стартовый скрипт с комментариями (`#`) и эхо-выводом.

---

## Аргументы командной строки

| Аргумент | Описание |
|----------|----------|
| `--vfs-path` | Путь к XML-файлу VFS. |
| `--script` | Путь к стартовому скрипту. |

---

## Формат VFS (XML)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<vfs name="MyVFS">
    <dir name="home">
        <dir name="user">
            <file name="readme.txt">Содержимое файла.</file>
        </dir>
    </dir>
    <file name="motd.txt">Привет!</file>
</vfs>
